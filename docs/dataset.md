# Dataset

Do not commit real personal data to this repository.

Use synthetic or properly anonymized examples covering:

- Email addresses
- Phone numbers
- PAN-like identifiers
- Aadhaar-like identifiers
- UPI-like identifiers
- IP addresses
- Non-sensitive text
- Sharing, requesting, general and incident contexts

Store raw private datasets outside the public repository. Commit only schema documentation and synthetic samples.
